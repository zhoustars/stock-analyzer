### 第 1 步：创建 GitHub 仓库

1. 打开 https://github.com/new
2. Repository name 填 `stock-analyzer`
3. 选择 **Public**（Render 免费套餐只能部署公开仓库）
4. 不要勾选 "Add a README file"
5. 点击 **Create repository**

---

### 第 2 步：推送代码到 GitHub

创建仓库后，GitHub 会显示推送命令，复制执行即可。格式如下：

```bash
git remote add origin https://github.com/你的用户名/stock-analyzer.git
git branch -M main
git push -u origin main
```

### 第 3 步：部署到 Render

1. 打开 https://render.com，用 GitHub 账号登录
2. 点击 **New +** → **Web Service**
3. 选择 **Build and deploy from a Git repository** → 连接你的 GitHub 账号
4. 找到 `stock-analyzer` 仓库，点击 **Connect**
5. Render 会自动检测到 `render.yaml`，配置已预填：
   - Name: `stock-analyzer`
   - Runtime: `Python`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn web_app:app --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 120`
6. 点击 **Create Web Service**

---

### 第 4 步：等待部署完成

- 首次部署约 2-5 分钟
- 完成后 Render 会提供一个域名，如 `https://stock-analyzer-abc123.onrender.com`
- 手机打开这个域名即可访问
